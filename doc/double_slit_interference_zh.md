# 双缝干涉

实验注意事项：

- 要注意仿真的时间范围。如果波长过大，会导致没有足够多的周期被记录。边缘的统计值会失去意义。
- 干涉与衍射的波都很小，需要用 gamma 矫正之后才能看清。

## 💡 双缝干涉条纹间距公式

条纹间距 $\Delta x$ 的公式如下：

$$\Delta x = \frac{\lambda L}{d}$$

## 各个参数的含义及关系

| 参数                | 名称                                      | 描述                                           | 关系                                 |
| :------------------ | :---------------------------------------- | :--------------------------------------------- | :----------------------------------- |
| $\mathbf{\Delta x}$ | **条纹间距** (Fringe Spacing)             | 两个相邻亮纹中心或两个相邻暗纹中心之间的距离。 | 决定了光斑之间的距离。               |
| $\mathbf{\lambda}$  | **光的波长** (Wavelength)                 | 入射光的波长。                                 | $\Delta x$ 与 $\lambda$ **成正比**。 |
| $\mathbf{L}$        | **双缝到屏幕的距离** (Distance to Screen) | 双缝平面到观察屏幕（墙壁）的距离。             | $\Delta x$ 与 $L$ **成正比**。       |
| $\mathbf{d}$        | **双缝的距离** (Slit Separation)          | 双缝之间的中心距离。                           | $\Delta x$ 与 $d$ **成反比**。       |

## 公式推导

这个推导基于两个核心假设：

1.  **相干光源：** 两个狭缝 $S_1$ 和 $S_2$ 产生频率和相位差恒定的光波。
2.  **小角度近似：** 屏幕距离 $L$ 远大于双缝间距 $d$（即 $L \gg d$）。

#### 1. 几何设置

- 设 $d$ 是双缝 $S_1$ 和 $S_2$ 之间的距离。
- 设 $L$ 是双缝平面到观察屏幕的距离。
- 设 $O$ 是屏幕上的中心点，位于双缝中垂线上。
- 设 $P$ 是屏幕上任意一点，其到中心点 $O$ 的距离为 $x$。

#### 2. 光程差 ($\delta$)

干涉的关键在于到达 $P$ 点的光波，从 $S_1$ 和 $S_2$ 出发所经过的**光程差**：

$$\delta = r_2 - r_1$$

其中 $r_1$ 是 $S_1$ 到 $P$ 的距离，$r_2$ 是 $S_2$ 到 $P$ 的距离。

为了简化计算，我们过 $S_1$ 作 $S_2 P$ 的垂线，垂足为 $A$。由于 $L \gg d$，光线 $S_1 P$ 和 $S_2 P$ 近乎平行。因此，$S_2 A \approx S_2 P - S_1 P = r_2 - r_1 = \delta$。

在直角三角形 $\triangle S_1 S_2 A$ 中：

- 斜边为 $d$。
- $\angle S_2 S_1 A$ 几乎等于光线 $S_2 P$（或 $S_1 P$）与中轴线（垂直于双缝平面）的夹角 $\theta$。

所以，光程差 $\delta$ 可以表示为：
$$\delta = d \sin\theta$$

#### 3. 亮纹（相长干涉）的条件

当光程差 $\delta$ 等于波长 $\lambda$ 的**整数倍**时，光波到达 $P$ 点发生相长干涉（亮纹）：

$$\delta = m \lambda \quad (m = 0, \pm 1, \pm 2, \dots)$$

代入 $\delta = d \sin\theta$:
$$d \sin\theta = m \lambda \quad (*)$$

#### 4. 小角度近似

因为 $L \gg d$ 且 $x$ 相对于 $L$ 较小，我们可以使用小角度近似：

$$\sin\theta \approx \tan\theta$$

在 $\triangle P O Q$ (其中 $Q$ 是双缝的中点) 中， $\tan\theta = \frac{x}{L}$。

因此，$$\sin\theta \approx \frac{x}{L}$$

#### 5. 亮纹位置 $x_m$

将小角度近似代入 $(*)$ 式，得到第 $m$ 级亮纹的位置 $x_m$:

$$d \left(\frac{x_m}{L}\right) = m \lambda$$

$$x_m = \frac{m \lambda L}{d}$$

#### 6. 条纹间距 ($\Delta x$)

条纹间距 $\Delta x$ 是相邻两条亮纹（或暗纹）中心之间的距离。设第 $m$ 级亮纹位置为 $x_m$ ，第 $m+1$ 级亮纹位置为 $x_{m+1}$。

$$\Delta x = x_{m+1} - x_m$$

代入亮纹位置公式：
$$\Delta x = \frac{(m+1) \lambda L}{d} - \frac{m \lambda L}{d}$$

$$\Delta x = \left( \frac{m+1 - m}{1} \right) \frac{\lambda L}{d}$$

最终得到条纹间距公式：

$$\Delta x = \frac{\lambda L}{d}$$
